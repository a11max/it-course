# Раздел 1: Введение в мультиагентные системы

## Обзор
В этом разделе мы знакомимся с локальными языковыми моделями и учимся запускать их из кода на языке Python. В качестве основы используется свободно распространяемая модель с платформы Hugging Face. Мы рассмотрим загрузку модели, подготовку запроса и получение текстового ответа.
